### 🚀 Quick Start

#### Prerequisites
- Node.js 20+ and npm


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/typescript-enterprise-analytics-sdk.git
cd typescript-enterprise-analytics-sdk
```

2. **Install dependencies**
```bash
npm install
```

#### Running

```bash
npm run dev
```
